# Runbook: Password reset (L1)
1. Verify identity: employee ID, manager name and callback to the registered number.
2. Reset the password in AD tools; tick "User must change password at next logon".
3. Never send a password by email or chat; read it out on the verified call only.
4. Record the verification method in the ticket work notes.
Escalate to WINTEL-L2 when: identity cannot be verified or the account is privileged.
