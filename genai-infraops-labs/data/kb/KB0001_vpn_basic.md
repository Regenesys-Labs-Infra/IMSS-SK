# KB0001 - VPN does not connect (basic)
Applies to: Remote Access VPN client 5.x, Windows 10/11
Symptoms: VPN shows 'authentication failed' or does not connect.
Resolution (L1):
1. Check whether the user's password has expired; guide them to the self-service reset portal.
2. Ask the user to restart the VPN client and reconnect.
3. If still failing, reinstall the VPN client from Software Centre.
Escalate to NETWORK-L2 when: more than 3 users at one site are affected.
